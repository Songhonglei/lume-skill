# 页面风格约束

保留蓝白科技工作台：浅灰画布、白色内容区、冷蓝色强调，系统中文字体。正文 14px，页面标题 24px，区块标题 16px，主要按钮至少 38px；面板圆角 6–8px，细边框，清晰表格。内容最大宽度 1440px，页面留白和区块间距一致。不增加营销首屏、大图、渐变光效或装饰性动画，不引入字体或 UI 依赖。

四类导航固定为 Skills、评测集管理、评测记录、系统配置。上传和开始评测优先，状态与版本就近展示；技术诊断默认收起。Skills 列表用于选择版本，详情提供下一步；评测集管理先搜索目录，再进入独立案例详情；版本记录另页查看。列表每列只放一种信息，描述、默认属性和案例数等放入详情信息。案例编辑保留一层案例导航和吸顶保存条，审查指南与完整校验按需打开。

配置按接入 Worker、登录 Codex、选择模型、检查连接组织。执行状态与评测结论分别展示，筛选在服务端分页前执行；不把当前页数量包装成全局统计。加载、读取失败、空数据分别展示，短时断连保留已有数据并说明错误。

控件有可见键盘焦点，确认框默认聚焦保留操作；小屏保留主链路，编辑区单栏、表格在自身容器内滚动。版本、附件和判分语义沿用原实现，不以视觉调整改变业务约束。

参考界面的信息层级与操作组织，不迁入私有前端源码、数据或素材。使用 frontend-design 完成实现，用户指定的蓝白主题和系统中文字体优先于技能的一般视觉探索建议。设计取舍与验收见[本轮改进](UI-IMPROVEMENTS.md)。


最新设计为“检索优先的蓝白资料台”，DFII 14（3 + 5 + 4 + 4 − 2）。保留主蓝 #1754d8、正文 14px、24px 间距与既有品牌，不新增字体、装饰资产、组件库或动画。通过搜索区、单一值表格、面包屑和聚焦编辑建立辨识度。分区与验收见[目录与详情重设计](verification/local/set-directory-2026-11-04.md)。
