# 页面风格约束

保留蓝白科技工作台：浅灰画布、白色内容区、冷蓝色强调，系统中文字体。正文 14px，页面标题 24px，区块标题 16px，主要按钮至少 38px；面板圆角 6–8px，细边框，清晰表格。内容最大宽度 1440px，页面留白和区块间距一致。不增加营销首屏、大图、渐变光效或装饰性动画，不引入字体或 UI 依赖。

四类导航固定为 Skills、评测集管理、评测记录、系统配置。上传和开始评测优先，状态与版本就近展示；技术诊断默认收起。Skills 列表用于选择版本，详情提供下一步；评测集管理先搜索目录，再进入独立案例详情；版本记录另页查看。列表每列只放一种信息，描述、默认属性和案例数等放入详情信息。案例编辑保留一层案例导航和吸顶保存条，审查指南与完整校验按需打开。

配置按接入 Worker、登录 Agent、选择模型、检查连接组织。执行状态与评测结论分别展示，筛选在服务端分页前执行；不把当前页数量包装成全局统计。加载、读取失败、空数据分别展示，短时断连保留已有数据并说明错误。

控件有可见键盘焦点，确认框默认聚焦保留操作；小屏保留主链路，编辑区单栏、表格在自身容器内滚动。版本、附件和判分语义沿用原实现，不以视觉调整改变业务约束。

列表和次要操作统一使用蓝色文字链接：无边框、无装饰箭头，14px 字号，常用链接点击高度至少 32px，悬停显示下划线。文案直接写“详情、维护、查看、报告、下载”，省去“进入、继续、查看完整”等重复引导；必要的对象和影响范围保留在上下文、提示或确认框中。保存、启用、提交和危险操作的确认保留按钮层级，禁用、忙碌和键盘焦点状态不变。见[链接与文案走查](verification/local/action-links-2026-11-04.md)。

高频操作以少步骤为先：操作列可同时显示详情、案例、评测，或停止、重试，不为减少按钮增加点击。信息列一列一个字段，描述和诊断进入详情；长案例结果先显示数量，按需展开、搜索、筛选及分页，短清单直接展示。标题已说清的内容不重复写副标题，必要的版本、数量、模型调用和恢复条件保留；不改写用户原文、原始报告或历史证据。

状态统一由 `presentation.ts` 定义：进行中蓝色，完成/通过绿色，等待/未完成橙色，停止/离线/撤销灰色，失败红色。执行完成与质量通过分别表达；“执行失败”与“未通过”按执行和结论区分。停止后不再提示等待，重试的新执行不沿用旧结果，历史记录可单独查看。见[文案与状态走查](verification/local/copy-status-2026-11-04.md)。

Worker 接入先给可复制的 Agent 安装指令，再生成短期接入指令；已安装可直接继续。打开安装页不生成授权码，避免安装期间过期。安装、授权、在线、登录和真实模型调用分别说明，跨电脑的中心地址限制就近提示。见[接入向导验收](verification/local/worker-onboarding-2026-11-04.md)。

用户侧统一使用“登录 Agent”“Agent 登录”“Agent 连接”“Agent CLI”“Agent 语义裁判”，包含页面、弹窗、提示词和新产生的服务端提示。实际可执行命令、参数、配置键、原始报告和历史证据保留准确名称；旧系统默认连接名只在展示时兼容，自定义连接名保持原文。见[术语走查](verification/local/audit/UGLIC-agent-terms.md)。

参考界面的信息层级与操作组织，不迁入私有前端源码、数据或素材。使用 frontend-design 完成实现，用户指定的蓝白主题和系统中文字体优先于技能的一般视觉探索建议。设计取舍与验收见[本轮改进](UI-IMPROVEMENTS.md)。


最新设计为“检索优先的蓝白资料台”，DFII 14（3 + 5 + 4 + 4 − 2）。保留主蓝 #1754d8、正文 14px、24px 间距与既有品牌，不新增字体、装饰资产、组件库或动画。通过搜索区、单一值表格、面包屑和聚焦编辑建立辨识度。分区与验收见[目录与详情重设计](verification/local/set-directory-2026-11-04.md)。

联动选择恰有两个有效选项时使用原生单选构成的滑块，保留键盘、必填和禁用状态；更多选项保留下拉。导入先选新建或已有评测集，再填写名称或选择目标。文件和目录分别说明格式，错误在弹窗内显示并聚焦，保留输入与可用预览，允许原文件重试。见[导入交互验收](verification/local/import-controls-2026-11-04.md)。

查询结果分页统一放在表格右下角，默认 20 条，可选 30、50、100 条；版本、Worker、案例结果及案例/文件清单同样支持。普通详情放右侧抽屉，评测详情使用大抽屉；复杂案例和完整报告使用新窗口。默认列表不自动打开首条详情，关闭抽屉保留页码、筛选与焦点。验收见[分页与详情](verification/local/pagination-drawers-2026-11-05.md)。
