# 工作台界面改进 · 2026-11-04

本轮沿用蓝白科技主题、品牌与四页导航，改善阅读与主要操作。设计方向为“清晰蓝白工作台”；基于现有产品约束，DFII 为 14（3 + 5 + 4 + 4 − 2），不额外建立视觉框架。

- **Skills**：资源概况、执行环境提示、选择版本后继续维护或开始评测；主操作集中在详情。
- **评测集**：顶部选择 Skill 和评测集，只保留案例侧栏；保存条吸顶，“保存并启用”为主操作，“仅保存版本”和导出放入更多操作。审查指南默认收起，启用版本明确标识只读。
- **记录**：服务端按 Skill、状态、结论、日期筛选后分页；结果和失败原因优先展示，输入与版本信息可展开。切换筛选同步切换详情。
- **配置**：按 Worker → Codex 登录 → 模型 → 连接检查引导；运行环境与账号默认收起。保存配置不调用模型，连接检查仍需明确点击。
- **共同体验**：正文 14px、主按钮 38px；小屏编辑单栏。读取中、空结果、读取失败区分；短时断连保留已读记录。未保存离开、取消任务、撤销 Worker、移除案例使用统一确认框，默认保留。

浏览器验证发现快速连续请求可能先收到成功、后完成数据库提交，造成紧接着保存返回 404。所有数据库依赖显式使用函数作用域，在返回 HTTP 成功前提交；最低 FastAPI 版本与现有锁定版本 0.161.1 对齐，其他包版本未变。回归测试在修复前失败、修复后通过。参见[FastAPI 官方作用域说明](https://fastapi.tiangolo.com/tutorial/dependencies/dependencies-with-yield/#early-exit-and-scope)。

完整验证见[验收收据](verification/local/ui-refinement-2026-11-04.md)和[UGLIC 复核](verification/local/audit/UGLIC-ui.md)，筛选参数见[运维说明](OPERATIONS.md#评测记录筛选)。本轮使用隔离合成数据验证界面及协议，没有新增真实模型调用；历史真实模型、Docker 和平台验收仍按各自收据理解。源码合并不会更新此前生成的候选 ZIP，也不代表正式 Release 或镜像发布。


## 原评审建议落地对照

第一轮已覆盖原计划第一、二、三批的大部分；本轮收齐剩余细节，详见[后续验收](verification/local/ui-followup-2026-11-04.md)。

| 建议 | 已落地内容 |
| --- | --- |
| 字号、控件、间距与对比 | 14px 正文、38px 主按钮、统一间距；本轮加强辅助文字、焦点和重排 |
| 编辑层级 | 顶部 Skill / 评测集选择，版本与当前状态就近，只留案例导航 |
| 保存动作 | 主操作保存并启用，草稿次操作；更多收纳保存版本/导出，本轮说明导出快照与未保存内容 |
| 审查与校验 | 指南按需展开、字段提示保留；本轮新增结构状态与错误源码定位，不做质量自动通过或强制勾选 |
| Skills 下一步 | 无案例准备、草稿维护、已启用评测，版本和评测集参数一致；在线不代表调用已验证 |
| 统一确认 | 未保存离开、取消、撤销、移除案例统一；本轮补文件删除、焦点返回与菜单键盘行为 |
| 记录检索与详情 | 全局筛选后分页、明确详情区、结论和失败原因优先；本轮补往返定位及日志错误 |
| 配置路径 | Worker → 登录 → 模型 → 检查连接，环境与账号折叠，无隐式调用 |
| 加载/空态/失败 | 初次读取与空数据分开、可重试、断连保留记录；本轮补细分详情和日志错误 |
| 轻量整体情况 | Skills、草稿和已备案例来自真实资源，不用当前页伪造全局指标 |
| 保存上下文与键盘 | 本轮补非首案例、源码文件与正文位置保持，Tab/逃逸/安全默认/跳转焦点验证 |

不搬入财务字段、内网同步、录制链路、多模式、多裁判或多租户。采用明确详情区已满足记录阅读需要，不再叠加抽屉；不新增总览页或装饰统计。读屏器全流程与完整 WCAG 合规未宣称验收。
