# Skill Eval 页面交互整改验收

2026-11-07。范围为 Skill Eval 的八项交互和布局整改，基于合集 main `12f192b` 整合。

## 行为

- 区分前置条件失败、判分未执行和判分未通过。
- 重跑前展示冻结的 Skill 修订、评测集版本、模型和案例数，提供使用当前版本新建评测的入口。
- 同名 Skill 选择项展示修订和短 ID。生成草稿明确选择新建评测集或写入已有评测集，默认评测集不会被新建操作替换。
- 保存成功而启用失败时打开已保存版本，显示失败原因并允许单独重试启用。启用前核对入口移到启用操作旁。
- 窄屏任务和 Worker 列表直接显示状态、结论和详情入口。
- 手机案例编辑使用当前案例选择器及上一条、下一条导航，保存操作固定在底部。
- 任务详情常显冻结版本和模型，报告入口位于案例结果上方，并提供未通过案例快捷筛选。
- 模型保存与检查集中展示。检查绑定保存的配置 ID 和连接，回执记录完成时间，配置改变后显示待重新检查。旧回执缺少配置身份时要求重新检查。

## 验证

11/06 浏览器实测覆盖 1440、900、390px；编辑器另外检查 320px。验证了重跑取消与确认、新建和已有评测集归属、同名 Skill、未执行判分、报告下载摘要、模型配置变更后的检查失效，以及保存后注入启用失败并成功重试同一版本。生成与重跑流程使用隔离实例和合成协议回执。

11/07 在最新 main 上重跑 61 项后端测试、40 项前端测试、Ruff、TypeScript/Vite 构建、公开候选扫描、两种 Worker ZIP 构建及 Compose 配置检查，均通过。对应 PR 的 GitHub Actions 结果以该 PR 检查记录为准。

11/06 本地中心更新后，原会话、Worker 身份及 9 条任务可读，部署的前端产物与本地构建摘要一致。两次真实连接检查失败；同一 Worker 的独立诊断捕获到上游 HTTP 401 Unauthorized。该结果保留为模型登录待处理项，不能作为真实模型验收通过的证据。服务端实际模型身份未核实。
