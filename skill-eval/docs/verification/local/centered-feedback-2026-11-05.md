# 提示反馈走查

2026-11-05，相对 main `d7b1f8f`。frontend-design 延续蓝白资料台与系统字体，DFII 14；只调整反馈层级、错误归属与恢复路径。

## 统一规则

操作成功与失败共用居中浮层，3 秒自动消失，保留关闭按钮。最后一次操作替换上一条并重新计时；计时器按消息标识清理，旧计时器不能关闭新提示。使用原生 manual Popover 进入浏览器顶层，并将提示挂到当前 modal 内，使关闭按钮不受 modal 的 inert 限制。弹窗关闭或切换时同步挂载位置，不抢占原操作焦点。

格式与参数校验在输入旁持续展示，不走瞬时 Toast。离线、读取失败、过期、只读、未保存等属于持续状态，仍在对应区域提供信息和恢复入口。

## 覆盖入口

| 入口 | 输入校验 | 操作反馈 |
| --- | --- | --- |
| Worker 接入 | 只读指令没有填写校验 | 复制、生成失败均为居中提示 |
| Skills 上传及新增版本 | ZIP/目录格式错误紧贴上传区域；新增版本错误留在抽屉内 | 保存、去重及其他失败居中提示 |
| 评测集导入 | 入口、JSON、路径与参数错误留在弹窗的导入组件旁 | 网络/保存失败与导入成功居中提示；保留输入与预览 |
| 案例编辑 | YAML/表单映射错误放在案例表单或源码旁；完整结构问题保留定位入口 | 保存、启用、校验成功和其他操作失败居中提示 |
| 模型与账号 | 连接、模型、密码、初始化口令分别就近提示 | 保存及操作失败居中提示 |
| 任务提交 | 数量范围/整数错误紧贴数量输入，其他 422 错误按字段展示 | 网络与其他提交失败居中提示；停止、重试沿用全局反馈 |

任务确定被 422 拒绝后恢复参数可编辑；网络未知结果仍锁定原提交内容及请求标识，避免重试重复创建任务。

## 浏览器实测

- 安装指令复制提示在 modal 内进入 `:popover-open`，中心坐标为视口正中，命中测试确认没有被遮罩挡住；焦点留在复制按钮。截图存于本地验收目录。
- 成功提示约 3185ms 后消失，安装弹窗保持打开；关闭提示按钮仅关闭提示，不关闭弹窗。
- 复制后关闭安装弹窗并打开 Worker 抽屉，提示跟随新抽屉且仍能命中、关闭。
- 隔离 QA 模拟断网生成接入指令，失败提示约 3057ms 后消失，生成按钮恢复可用；请求未到达服务端，未生成接入码。临时网络设置已恢复。
- 缺少评测入口的 ZIP 返回“需要唯一的 evals/eval.yaml 或 evals.json”，错误留在导入组件旁，超过 3 秒仍保留，没有生成 Toast。
- 新增 Skill 版本时上传缺少 SKILL.md 的 ZIP，错误显示在 Skill 抽屉内，未落到背景页面；没有创建新版本。
- 目标案例数填写 31，数量输入下方提示 1–30 的整数，提交禁用；改为 5 后提示清除。没有提交模型任务。
- 390px 视口下，document 为 390px，Toast 中心为 (195,422)，与 390×844 视口中心一致；关闭按钮可用。手机仿真中的指针映射不可靠，使用键盘触发校验布局；桌面指针关闭已验证。视口已恢复。
- 两次复制相隔约 1.8 秒，第二次复制后 2903ms 仍可见、3063ms 首次观察到消失，验证从最后一次重新计时。复制后的剪贴板已恢复。
