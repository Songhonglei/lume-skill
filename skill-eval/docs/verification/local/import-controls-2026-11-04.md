# 导入评测集交互验收

2026-11-04，相对 main `be88d3c`。保留蓝白资料台、系统字体和已有 API。

## 改动

- 联动选择恰有两个有效选项时显示滑块；动态资源、版本、执行记录同样适用。更多选项保留下拉；禁用的占位项不计入可选数量。
- 导入保存位置明确分为新建与已有评测集，按选项显示名称或目标；没有已有评测集时直接新建。
- 文件与目录分别说明入口和引用文件，JSON 示例按需展开。读取、预览、保存失败均显示在弹窗内并聚焦；新文件清除旧预览，保存失败保留预览和输入；可重选同一文件。
- 仍然保存为草稿，不切换已启用版本；结构校验问题允许先存草稿，之后修复。

## 实测

隔离 QA 的 126 个合成 Skill 中，使用 ui-directory-125 验证：

1. 新建/已有滑块方向键切换正确，名称输入往返后保留。只有一个目标时为普通选择，两个目标时自动变为滑块；裁判三选项与主配置三个连接保留下拉。
2. 缺入口 ZIP、无效 JSON、缺入口目录分别展示原 API 错误；提示在 dialog 内且获焦，没有在遮罩后的全局提示新增异常。同一错误 ZIP 可再次选择并重新请求。
3. 合法 JSON 目录从错误状态恢复，预览结构通过并新建“导入控件验收”草稿，包含一个案例。
4. 选择已有目标“默认评测集”，上传合法原生 ZIP；模拟浏览器断网保存，弹窗保留五文件预览与目标，显示恢复后重试。恢复网络重试成功，进入所选目标详情。
5. 回到目录，新建目标未启用、草稿数 1；原目标启用版本仍为版本 2、草稿数由 1 增至 2。没有覆盖原版本。
6. Skills 详情的两个评测集滑块切换后，案例数说明和“开始评测 / 维护案例”按目标联动；未启动任务。
