## 最终行为

- 删除四页重复副标题、配置页重复模型说明和登录页口号。精简生成、排队、只读与格式提示；保留模型调用、版本、数量、不可变历史及恢复边界。
- 状态和颜色由 `presentation.ts` 共用：进行中蓝色、完成/通过绿色、等待/未完成橙色、停止/离线/撤销灰色、失败红色。“执行失败”和“未通过”分别用于执行状态与评测结论；执行记录“已结束”不代表质量通过。
- 停止请求区分“停止中”和“已停止”。停止后缺结果的案例显示“未完成”，明确没有完整结果；无草稿或产物时不再提示继续等待。保留原有结果，不改写原报告。
- 重试排队时不再自动选中上一次执行、结论和产物；历史记录仍可选择查看，并可直接返回当前任务。无效的旧执行选择回落到当前任务。
- Skills 分为 Skill、版本、启用案例、案例状态；任务 ID 独立一列。名称最多显示两行并保留完整可访问名称和 title，宽表在容器内滚动。Worker 工具版本、诊断及完整检查消息移入详情。
- Skills 操作列直达详情、案例和评测；无案例则准备案例，草稿可维护。任务操作列直达停止或重试，仍保留停止确认。Worker 检查连接保持直达，并注明调用模型。
- Skills 每页 20 条，全资源搜索后分页。超过 8 条的案例结果先显示数量，展开后可搜索名称/ID、筛选结论，每页 20 条；短清单直接展示。编辑器长案例/文件侧栏增加搜索，Worker 长列表限制高度并保留表头。
