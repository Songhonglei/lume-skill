## 发现并修复的三个问题

1. **macOS 新包安装崩溃。** 初始 ccaf6e4 候选用 uv 提供的独立 Python 3.12.12 全新安装，venv 复制解释器后无法定位相对动态库，退出 -6。相同解释器、相同机器的符号链接 venv 正常。安装器改为符号链接，并用实际 Python/pip 运行及带空格目录做回归。最终 ZIP 在新目录安装成功，导入文件与私有工具来源均已核对；失败候选与日志保留。
2. **中心不可达只显示 Failed to fetch。** 实际停止自己的 API 后复现，改为中文中心/网络恢复指引；主动 AbortError 仍原样传递。再次停中心、从网页请求，出现新提示；恢复后原管理员会话、Worker 身份与启用版本保持。离线时页面可能显示缓存内容，不能将缓存状态当作实时可达保证。
3. **模型产物 result.json 被当成标准报告。** 两个真实脚本案例底层均 PASS，但产物也叫 result.json，中心的后缀匹配将三个 JSON 都当作报告，误标 INCOMPLETE。现在只识别标准报告根路径，仍要求恰好一个；缺失、嵌套伪报告及多份标准报告不能通过。保留版本、来源摘要与模型配置核对。新增协议回归先红后绿，原始真实产物离线重解析为 2/2；没有改写原任务历史。
