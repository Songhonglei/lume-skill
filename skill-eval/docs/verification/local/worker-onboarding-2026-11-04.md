# Worker 接入向导验收

2026-11-04，相对 main `900f8d7`。延续蓝白资料台，DFII 14；仅前端、测试及相关文档。

## 改进

- “接入 Worker”先打开安装页，直接复制给执行电脑上的 Agent；包含支持平台、Python/Git/Node/npm、私有安装器、固定 CLI、评测 Skill、独立目录、版本检查和登录准备。
- 安装页不生成授权码、不启动 Worker。已安装的电脑可以直接生成接入指令，包含实际中心地址、启动参数、一次性接入码、在线验收与失败恢复。
- 10 分钟有效期从请求开始保守计算；界面显示剩余时间，过期后隐藏旧指令并禁用复制，可重新生成。后端仍独立执行原有一次性/过期检查。
- 明确本机地址的使用范围；非 HTTPS 远程地址不能生成接入指令。指令不把接入码放入 Shell 参数，登录由用户在执行电脑完成，不上传 auth.json 或长期凭据。启动自动领取匹配任务和可能的模型费用在接入前说明。

## 验证

- 34 项前端测试与 TypeScript/Vite 通过；新增三项覆盖真实安装器/目录/版本契约、Shell 块语法、接入码不进入命令行、本机/远程地址与 HTTPS 前提。安装器 `--help` 与既有实现参数一致。
- 主预览打开安装页，指令包含安装器和评测 Skill，不含接入码；实际复制后内容正确，原剪贴板恢复。主预览授权记录打开前后均为 4，没有新增授权或注册。
- 隔离 QA 实际生成和重新生成接入指令，码随生成变化，含状态/登录目录参数、自动领取及模型费用边界；返回安装页不含接入码。QA 仅产生 3 个未兑换码，兑换数为 0，未注册真实 Worker、调用模型或更改登录。
- 在临时 QA 标签页用虚拟时钟模拟到期，界面显示“接入码已过期，请重新生成”，复制按钮禁用。该标签页关闭后虚拟时钟不影响主预览，未修改服务器时钟或过期策略。
- 390px 视口下 document 为 390px、Dialog 为 350px，操作按钮与文本均未横向溢出；恢复尺寸后关闭 QA 服务和标签页。

本轮验收的是安装/接入引导、模板命令契约与页面交互，没有重新执行一台全新电脑的安装或真实模型任务。安装器与 Worker 协议未改，历史平台与模型证据仍按原收据理解；不把命令语法、在线状态或容器 CI 当作新的模型验收。

[UGLIC 与 Skill 审计](audit/UGLIC-worker-onboarding.md)记录发布前判断；GitHub CI 成功后合 main，不自动发布正式安装包或镜像。
