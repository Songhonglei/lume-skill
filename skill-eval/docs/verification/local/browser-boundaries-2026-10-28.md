# 浏览器边界、运行快照与恢复验证

日期：2026-10-28（Asia/Shanghai）。基于 main `44e91039dc49b84a3b509fa18817e03d05119c10` 的本轮增量。固定 skill-up 0.14.0 / Codex CLI 0.162.1。完整脱敏机器收据见 [browser-boundaries-2026-10-28.json](browser-boundaries-2026-10-28.json)。本轮没有恢复原生 Linux x86_64 验证或执行正式发布。

## 发现并修复

1. **附件读取和保存时仍可从顶层导航离开。** 基线页面虽然禁用了编辑区，顶部导航和退出没有收到忙碌状态；慢速读取期间切到系统配置会卸载编辑器，附件尚未加入草稿。本轮将忙碌状态传递到应用层，保护导航、退出和离开页面事件，读取附件时显示状态提示，并稳定跨组件回调。
2. **同一次选择中的同名附件静默覆盖。** 原实现只检查草稿中已存在的附件。选择两个来自不同目录、同名的文件时，最后一个直接覆盖前一个。本轮统一检测已有文件和批内重复名，弹出一次确认并去重显示冲突文件名；取消保留原状，确认使用本次最后选择的内容。
3. **详情页遗漏排队等待原因。** 列表接口显示“等待匹配连接与版本的 Worker”，详情接口却没有该字段，页面无法显示引导。本轮让两个接口共用排队原因计算，领取后清除该提示；详情页增加“查看 Worker 状态”，系统配置说明离线检查和恢复后继续领取队列，无需重复提交。

新增回归先复现列表/详情不一致的失败，再验证匹配、离线、恢复和领取后的变化。新增附件测试覆盖批内重复、原文件不变、路径作用域及读取失败不变成空文件。

## 浏览器与真实接口

通过 ego-browser 在独立浏览器空间、独立 Compose 项目和空数据库中操作合成 Skill；原有验证实例、其他项目和用户服务未改动。初期 API/前端以只读源码和构建目录挂载便于验证，最终另建 ARM64 center 镜像，去掉源码挂载后核对后端与前端 bundle 摘要、原会话和三个任务，确认构建内容一致。

| 场景 | 结果 |
| --- | --- |
| 慢附件读取期间点击其他顶层页 | PASS；导航/退出/编辑区禁用，页面保留；完成后恢复并保留附件 |
| 批量读取中一个文件失败 | PASS；没有部分添加，显示可重试错误并恢复导航 |
| 已有附件加新附件，取消替换 | PASS；原内容不变，新附件没有加入，草稿不产生修改 |
| 同批两个同名文件 | PASS；只列一个冲突名，取消不添加，确认后最后选择的内容保留 |
| 延迟真实 PUT 后保存并启用 | PASS；全过程锁定导航/退出/版本切换，保存后是只读版本 |
| 导出附件 | PASS；6 个附件逐字节核对：CRLF、BOM、非法 UTF-8/NUL 二进制、空文件、慢读取文件和确认后的同名文件 |
| 管理员会话失效后保存 | PASS；真实注销接口使当前会话失效，后续保存触发 401；重新登录保留未保存草稿并可继续保存 |
| Worker 离线 | PASS；页面显示等待原因、状态入口和恢复说明；启动原 Worker 后原排队任务继续，无需新接入码 |
| 端口占用 | PASS；对自身测试端口发起冲突启动返回 125 和绑定诊断，原 API 前后健康，未结束原服务 |
| 900px 历史任务页面 | PASS；无整页水平溢出，旧冻结版本、输出和下载地址保持 |

慢读取、PUT 延迟和读取错误是明确的浏览器故障注入；实际文件读取、API、数据库和任务报告不伪造。管理员会话失效测试不等于 Codex OAuth 到期测试。离开页面事件已接入同一保护状态，本轮没有声称逐个操作系统的关闭/刷新原生提示框都已实测。

## 运行中切换版本

三个任务都通过网页确认发起，均为单案例真实评测、一个 attempt。没有生成任务或自动重新执行。请求模型为 gpt-6-luna，实际服务端模型身份仍未核实。

| 任务 | 冻结输入与操作 | 实际结果 |
| --- | --- | --- |
| 旧版任务 | Skill 修订 1、评测集版本 2；确认 RUNNING 时，从页面启用版本 4；切换后任务仍 RUNNING 且输入未变 | 1/1；LABEL: Hello WORLD |
| 切换后的新任务 | Skill 修订 1、评测集版本 4 | 1/1；LABEL: AFTER SWITCH |
| 新 Skill 复用旧案例 | Skill 修订 2、评测集版本 4（案例来源仍为 Skill 修订 1）；页面提示可继续复用；离线排队后由恢复的 Worker 领取 | 1/1；LABEL: AFTER SWITCH |

页面保留旧任务的版本 2、原案例标题和旧输出；三个原始报告 ZIP 均从中心下载并核对 SHA256。新增 Skill 版本和切换启用指针后，旧报告的下载摘要不变，冻结 Skill 源摘要前后相同。该证据补齐 AC-12 在本机单 Worker、ARM64 Docker 和浏览器路径下的场景，不扩展为其他架构或多 Worker 的新实测。
