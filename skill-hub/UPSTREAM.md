# Source and licenses

This directory includes application source, tests, deployment files, and reference documentation from [iflytek/skillhub v0.2.28](https://github.com/iflytek/skillhub/tree/v0.2.28), revision `b81af32f145c393c03051865031eae7bfbeaafa4`. The import includes the server, scanner, web, CLI, packaging, integrations, and their reference material. The upstream hosting workflows and agent workspace configuration are specific to their original repository.

LumaSkill changed the web branding, presentation, supported browser languages, and deployment packaging. The upstream [Apache License 2.0](LICENSE), component licenses, third-party notices, and original attribution are included in the source tree. The [LumaSkill marks](../assets/brand/) have a separate MIT license. Existing package names, published container coordinates, API identifiers, and data schema provide compatibility with the upstream release. Korean and Russian component fixtures remain under `web/test/` for upstream regression tests. The production Web bundle serves Chinese and English.

Upstream docs are available in [English](UPSTREAM-README.md) and [中文](UPSTREAM-README_zh.md).
