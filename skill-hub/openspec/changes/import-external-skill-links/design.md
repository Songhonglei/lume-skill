# 设计

用四种公开链接解析规则定位单个技能。GitHub 和 Skills.sh 从 GitHub 归档中选取技能目录，ClawHub 和腾讯 SkillHub 使用公开下载接口。请求使用固定服务地址和受限重定向，检查包大小与文件数量，复用现有包校验。上传方确认后服务端重新验证链接与提交包是否一致，将来源和内容一起提交到原有发布流程。

技能库聚合现有数据，按版本显示来源，历史 GitHub 同步版本归为外部。旧页面跳到对应常规入口，后台定时同步和管理接口在本发行版默认停用。此变更替代 separate-market-skill-sources 中的专用 GitHub 页面和用户侧来源筛选。兼容 API 的来源参数继续适用。
