# Luma Skill Hub 企业改版

## 方案

浅色使用 Skill Manage 的蓝灰工作台配色。深色保持同样的内容顺序、动作位置和层级。主页优先摆放真实搜索、技能库和发布入口，下方按需浏览热门、最近发布、接入指南与治理说明。全站共用 64px 顶栏、下划线导航与相同的页面边距。顶栏右上角的主题和语言选择记忆偏好，登录页也使用同一组控件。

LumaSkill 光棱图标复用仓库的品牌资产。产品默认名称为 Luma Skill Hub。网页语言为简体中文与 English，旧浏览器语言偏好回退到支持的语言。首页和全局布局移除原项目的多列页脚。

## 开发与验收

| 阶段 | 交付或验证 |
| --- | --- |
| 工作台 | 首页、技能库、技能详情、控制台、登录页共享布局与主题。可见品牌、favicon、CLI 接入提示和语言选择符合预期。 |
| 界面回归 | 检查中英文、桌面与手机、暗色切换、刷新保持、键盘操作、搜索结果与错误反馈。 |
| 业务回归 | 用隔离测试 Skill 逐一验证上传、扫描、通过、驳回、当前版本、指定版本下载、差异和非成员拒绝。 |
| 数据保留 | 只更换 Web 镜像，复核历史包 SHA-256、审批和审计记录。 |
| 仓库交付 | 通过类型、lint、单测和构建，提交项目源码、部署方法及许可。 |

## 企业工作台设置

- 页头只保留主标题和当前页面的操作。技能、空间和套装的实际内容及表单、错误、状态说明继续展示在各自位置。
- 头像菜单里的「设置」包含个人资料、账号安全、通知偏好和 API Token。「管理设置」按平台角色显示系统设置、用户、空间、标签、治理、GitHub 同步和审计等入口。
- GitHub 独立发现页由超级管理员从「管理设置」访问。其他访问者的旧链接转到技能库，可继续搜索已发布的 GitHub 技能。审批通过的仓库可由管理员在「GitHub 同步 → 采集配置 → 指定仓库」逐个加入。同步执行依赖部署时启用 GitHub 同步组件。
- 举报从技能详情的「更多操作」进入，由现有治理流程处理。
- Luma Compose 默认不注入浏览器活动分析配置。站点展示编辑在超级管理员的系统设置中。部署需要启用分析时可在本地 Compose 环境配置 `LUMA_SKILL_HUB_ANALYTICS_CONFIG` 和 `LUMA_SKILL_HUB_ANALYTICS_UPSTREAM`。
- 评分、评价、排行、推荐、邮件批次、套装与跨空间推广沿用现有流程。公开注册与资料审核沿用现有配置，企业 SSO 验收完成后再决定停用时间。
