# Luma Skill Hub 企业改版

## 方案

浅色使用 Skill Manage 的蓝灰工作台配色。深色保持同样的内容顺序、动作位置和层级。主页优先摆放真实搜索、技能库和发布入口，下方按需浏览热门、最近发布、接入指南与治理说明。全站共用 64px 顶栏、下划线导航与相同的页面边距。顶栏右上角的主题和语言选择记忆偏好，登录页也使用同一组控件。

LumaSkill 光棱图标复用仓库的品牌资产。产品默认名称为 Luma Skill Hub。网页语言为简体中文与 English，旧浏览器语言偏好回退到支持的语言。首页和全局布局移除原项目的多列页脚。

## 开发与验收

| 阶段 | 交付或验证 |
| --- | --- |
| 工作台 | 首页、技能库、技能详情、控制台、登录页共享布局与主题。可见品牌、favicon、CLI 接入提示和语言选择符合预期。 |
| 界面回归 | 检查中英文、桌面与手机、暗色切换、刷新保持、键盘操作、搜索结果与错误反馈。 |
| 业务回归 | 用隔离测试 Skill 逐一验证上传、扫描、通过、驳回、当前版本、指定版本下载、差异和非成员拒绝。 |
| 数据保留 | 只更换 Web 镜像，复核历史包 SHA-256、审批和审计记录。 |
| 仓库交付 | 通过类型、lint、单测和构建，提交项目源码、部署方法及许可。 |

## 功能精简清单，待确认

| 编号 | 现有功能 | 建议 | 取舍 |
| --- | --- | --- | --- |
| 1 | 外部 GitHub 技能发现、导入与同步 | 内网白名单导入场景保留管理员入口。其他实例可先隐藏外部发现。 | 可减少公网依赖与重复来源。已有 GitHub 技能需要继续查看来源、版本和授权信息。 |
| 2 | 评分、文字评价、公开排行与运营推荐 | 先收起社区入口和热门板块。 | 企业通常通过维护者、标签、扫描与审核记录判断可信度。已有评价数据可保留，收藏可用来快速定位。 |
| 3 | 公开注册和资料变更审核 | 企业 SSO 已覆盖时关闭自注册，把姓名和头像管理交给企业目录。 | 本地管理员与应急登录应先验收。公开注册和资料审核分别控制。 |
| 4 | 举报和社区治理 | 把举报入口移到详情更多菜单，保留管理员处理和紧急下架。 | 发现问题时，使用者仍有渠道上报。 |
| 5 | 通知与订阅 | 先保留发布审核通知和版本订阅，按接入需要决定邮件批次功能。 | 审核、版本和邮件渠道各有不同用户。 |
| 6 | Skill 套装和跨空间推广 | 没有批量分发需求时收起入口。 | 多 Skill 一起安装、团队向全员推广时仍有用途。收起前检查现有套装和申请。 |
| 7 | 活动分析、站点展示编辑 | 小规模内部试点可关闭可选分析采集，站点展示集中到管理员。 | 业务审计继续用于定位发布、撤回与权限变动。 |

发布审核、安全扫描、版本历史、撤回、可见范围审批、空间成员权限和 API Token 是分发的核心能力。以上七项等确认后再处理入口、权限或数据。
