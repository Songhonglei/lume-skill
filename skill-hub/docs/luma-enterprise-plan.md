# Luma Skill Hub 企业改版

## 方案

浅色使用 Skill Manage 的蓝灰工作台配色。深色保持同样的内容顺序、动作位置和层级。主页优先摆放真实搜索、技能库和发布入口，下方按需浏览热门、最近发布、接入指南与治理说明。全站共用 64px 顶栏、下划线导航与相同的页面边距。顶栏右上角的主题和语言切换各用一个图标，点击后切换并记忆偏好，登录页也使用同一组控件。

LumaSkill 光棱图标复用仓库的品牌资产。产品默认名称为 Luma Skill Hub。网页语言为简体中文与 English，旧浏览器语言偏好回退到支持的语言。首页和全局布局移除原项目的多列页脚。

## 开发与验收

| 阶段 | 交付或验证 |
| --- | --- |
| 工作台 | 首页、技能库、技能详情、控制台、登录页共享布局与主题。可见品牌、favicon、CLI 接入提示和语言选择符合预期。 |
| 界面回归 | 检查中英文、桌面与手机、暗色切换、刷新保持、键盘操作、搜索结果与错误反馈。 |
| 业务回归 | 用隔离测试 Skill 逐一验证上传、扫描、通过、驳回、当前版本、指定版本下载、差异和非成员拒绝。 |
| 数据保留 | 只更换 Web 镜像，复核历史包 SHA-256、审批和审计记录。 |
| 仓库交付 | 通过类型、lint、单测和构建，提交项目源码、部署方法及许可。 |

## 企业工作台设置

- 页头只保留主标题和当前页面的操作。技能、空间和套装的实际内容及表单、错误、状态说明继续展示在各自位置。
- 「控制台」的左侧菜单按「个人设置」和「技能与数据」分组。前者包含个人资料、账号安全、通知和 API Token，后者包含我的技能、我的套件、空间、收藏、订阅和我的审核。有审核权限的成员从头像菜单进入独立的「审核中心」。「后台管理」按平台角色显示全局设置和治理入口。
- GitHub 独立发现页由超级管理员从「后台管理」访问。其他访问者的旧链接转到技能库，可继续搜索已发布的 GitHub 技能。审批通过的仓库可由管理员在「GitHub 同步 → 采集配置 → 指定仓库」逐个加入。同步执行依赖部署时启用 GitHub 同步组件。
- 举报从技能详情的「更多操作」进入，由现有治理流程处理。
- Luma Compose 默认不注入浏览器活动分析配置。站点展示编辑在超级管理员的系统设置中。部署需要启用分析时可在本地 Compose 环境配置 `LUMA_SKILL_HUB_ANALYTICS_CONFIG` 和 `LUMA_SKILL_HUB_ANALYTICS_UPSTREAM`。
- 评分、评价、排行、推荐、邮件批次、套装与跨空间推广沿用现有流程。公开注册与资料审核沿用现有配置，企业 SSO 验收完成后再决定停用时间。

## 页面视觉与头像

统一主标题、表面和操作密度。顶栏的主题、语言、通知和账号分别使用单个图标。语言按钮用「中」或「EN」表示当前语言。工作台、技能库、开源技能和后台管理复用相同的页面标题样式。

个人资料提供 12 个动物和 8 个植物 SVG。服务端只接收预设编号，头像随账号保存在原有资料中。昵称审核继续沿用现有流程。

## 平台品牌

超级管理员在「后台管理 → 系统配置 → 站点与首页 → 名称与标识」设置平台名称和 Logo。保存后，导航、登录页、浏览器标题和内置接入文案使用平台名称。Logo 支持小于 1 MB 的 PNG 或 JPEG，系统会居中裁成方形、缩至最长边 384 像素并保留透明背景。浏览器图标自动从同一 Logo 生成 64 × 64 像素的 PNG。清除 Logo 后，顶栏和浏览器标签页共用默认标识。
