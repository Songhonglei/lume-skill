# 清爽蓝色工作台 · 0.3.2.dev11

日期：2026-11-04。按用户「最急、最少、最像」及「简单、省心、说人话」原则重新设计结果列表。核心规则：**信息列一列一个字段；操作列按频率展示，优先减少操作步骤。** 蓝色科技主题保持。

## 设计方向

方向为克制、清晰的蓝色工作台。辨识点是蓝色细线状态导航、整齐的单行结果和就近的问题数字入口；不增加装饰、在线字体或前端框架。

设计可行性评估（DFII）：视觉影响 3、场景适配 5、实现 5、性能 4、一致性风险 3，总分 **14**。现有本机中文字体用于正文与名称，等宽数字用于版本和数量；优先保证中文、离线访问和熟悉的控件。主色 `#2467df`，浅冷灰背景和白色内容；基础间距 8px，桌面结果行 60px、问题行 56px，手机主要操作约 44px。动效仅保留必要悬停反馈和既有减少动态效果支持。

## 原则落地

| 原则 | 实现 |
| --- | --- |
| 最急 | 审计、报告/进展、详情、下载等高频操作直接展示；必修数字直接打开固定版本抽屉 |
| 最少 | 去掉名称下的长描述、版本下的版本数、状态下的计数、维护者下的时间；去掉任务记录中重复的报告保存状态；操作列可同时展示多个高频操作，避免多点一次菜单；数量不作为简洁标准 |
| 最像 | 版本、状态、必修、建议、维护者、时间各自成列；同类数字纵向对齐；Skill、任务、问题、版本历史及设置表格使用一致规则 |
| 说人话 | 未生成结果显示「—」；任务执行与检查结论分开；Skill 的综合审计进展称为「审计状态」，不把等待执行重复写成检查结论 |

## 各结果列表

| 页面 | 默认可见字段 | 按需查看 |
| --- | --- | --- |

| 任务中心与版本活动 | 名称、版本、任务类型、执行状态、检查结论、必修、建议、创建时间、操作 | 报告保存状态、执行诊断及报告原文在任务详情 |
| 问题列表 | 问题摘要、级别、规则、文件位置、查看；有写权限时另有选择列 | 完整描述、修改建议、验证方法和文件证据在问题抽屉 |
| 版本历史 | 版本、使用状态、审计状态、登记时间、大小、下载 | 点击版本看对应文件，点击已有审计状态看固定报告 |
| 设置 | 原有成员/机器字段 | 保留原分组与权限，应用相同的表格与手机排布 |

桌面名称、版本、文件等长字段单行省略；完整内容保留在悬停提示或详情。被审计内容及报告均未改写。手机按字段重排，问题卡片通过摘要/位置打开详情；完整建议不在每条记录中重复常驻。

操作列是「一列一个字段」的例外：Skill 库直接展示审计（有写权限时）、报告/进展（有记录时）、详情和下载；任务列表直接展示报告/详情与对应版本；版本历史直接展示查看和下载。低频归属、导入新版本等保留在详情页。

质量概览改为轻量状态标签；「全部 Skill」与「我维护的」不再使用重复的双按钮，维护范围改为一个开关。搜索、筛选保留、问题选择、原有授权、焦点回归及安全报告阅读继续可用。
