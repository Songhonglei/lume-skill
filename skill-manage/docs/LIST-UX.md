# 列表、详情与提示 · 0.3.2.dev13

日期：2026-11-05。保留蓝色主题和简洁文案，统一列表操作。设计沿用清爽蓝色工作台：固定操作节奏、表格右下分页、右侧只读详情；DFII 14，无新增框架或运行依赖。

## 分页

统一默认每页 **20** 条，可选 **20 / 30 / 50 / 100**，分页组件位于结果表格右下角。空结果和只有一页时也保留容量选择；翻页、切换容量不清空筛选或已选问题。筛选或容量变化回到第一页，记录变少时自动校正页码。

| 列表 | 分页方式 |
| --- | --- |
| Skill 库、版本历史、文件搜索、问题与建议 | 前端对完整结果分页 |
| 任务中心、版本审计与修复记录 | 原有后端游标分页 |
| 成员、执行机器 | 前端对完整结果分页 |
| 接入码记录、任务执行记录 | 原有后端游标分页 |
| 执行尝试、修复轮次、复审剩余问题、轮次文件差异 | 前端对已保存记录分页 |

任务历史同时提供 `report_available`，修复任务仅在已有保存的复审报告时启用报告入口。后端历史接口默认值同步为 20，仍接受 1–100，保持既有客户端兼容。游标绑定用户、筛选及插入快照的规则保持，不改为一次拉取全部历史。失败时恢复分页状态并允许重试；切换页面或会话后旧请求不覆盖新列表。原文、报告正文、目录导航、筛选选项和授权说明不作为查询结果拆页。

## 固定操作位

- Skill 库：**审计 → 报告 → 详情 → 下载**。
- 任务及版本活动：**报告 → 详情 → 版本**。
- 版本历史：**详情 → 下载**。
- 成员：**详情 → 启用/停用**；机器与接入码：**详情 → 撤销**。
- 问题、执行记录、执行尝试、轮次与差异：**详情**。

同类表格每项动作有固定宽度和顺序。不允许的操作显示不可交互的 `-`，保留原位置；缺少报告时不借用报告位展示进展。只读用户的审计位同样保留 `-`。可点击项继续服从服务端权限，前端占位不构成授权。

## 详情与新窗口

- 所有表格「详情」从右侧打开，不替换当前列表。Skill、版本、任务、成员、机器、接入码、执行记录及复审问题展示各自只读摘要。
- 问题抽屉保留建议、验证方法及固定版本证据；差异抽屉展示已保存文本差异，不执行包内代码。
- 完整报告、文件阅读和复杂任务页面从新窗口打开，带 `noopener noreferrer`；版本入口绑定原版本。抽屉提供「打开完整页面」，关闭后返回原列表位置。
- 抽屉关闭或切换账号后，晚到响应不重新展示数据。

## 提示

- 必填、长度、URL/名称/版本格式、文件格式/大小及服务端已知字段校验，紧贴对应输入组件展示，关联 `aria-describedby`；修改后清理原提示，不使用全局 toast。
- 其余短时操作反馈统一屏幕居中浮层，**3 秒自动关闭**，保留手工关闭。新提示替换旧提示并重新计时，不抢输入焦点。
- 浮层使用浏览器顶层 popover；在模态弹窗内仍可见、可手工关闭。关闭所属弹窗时清理并回收提示节点，下一次提示仍可使用。
- 运行状态、授权说明和已保存的诊断结果属于页面内容，保留为可查记录，不替换为会消失的 toast。
