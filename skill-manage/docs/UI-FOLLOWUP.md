## 两轮建议的覆盖

原体验评审将实施分为两轮。dev8 已同时完成第一轮的 Skill 库/详情/问题抽屉/焦点保护，以及第二轮的安全报告阅读、导入精修、手机任务页和设置分组；见 [首轮实现](UI-IMPROVEMENTS.md)。dev9 补齐仍需多次跳转和反复操作的细节。

| 剩余借鉴 | dev9 的行为 |
| --- | --- |
| 列表就近查看问题 | Skill 库、任务列表及版本活动里的非零问题数可直接打开固定版本抽屉；支持查看证据、选择问题及进入原有修复授权，无需先跳转长报告 |
| 概览帮助下一步 | Skill 库的全部/需要处理/执行中/未审计可点击筛选，与搜索、维护范围和结论下拉联动；统计来自已读取的全量 Skill 列表，范围明确为当前版本，不新增逐行请求 |
| 大量问题易于处理 | 问题按描述、规则、文件和建议搜索，每页 25 项；选择本页、清空已选、跨页及跨分类保留。待复核项不加入自动修复选择，清空需要用户主动点击 |
| 抽屉连续查看 | 同一问题抽屉有上一条/下一条、位置计数和固定版本证据；迟到文件响应不会覆盖下一条。关闭后回到原触发按钮，嵌套抽屉逐层返回 |
| 文档操作就近 | 报告和文件可复制原文；文件目录支持搜索和复制路径。复制受浏览器限制时，提供只读文本与手动全选，不丢失原文 |
| 加载与连接可恢复 | 页面加载有状态，失败提供重试/返回；轮询断网保留记录并显示重试连接，连接恢复后消除提示或提示新进展。网络和不可解析响应使用中文说明 |
| 小屏与会话收口 | 手机抽屉和搜索/选择工具条重排、主要触控目标加大；登录过期返回登录页时，清空模型草稿、查询、选择和历史状态，并关闭已打开弹窗 |

只读用户可查看列表与证据，不显示选择及修复入口；写操作仍经过原有授权表单。选择本页只影响当页可自动修复的问题，不隐式全选隐藏项；原有默认 ERR 选择行为保持。

## 验证

- 8 项 Node 原生测试通过：安全阅读与语义状态、会话清理、快捷过滤、字面量问题搜索、排除待复核项的选择，以及 61 项合成数据的分页/筛选收口。全部静态脚本语法、Ruff 和差异检查通过。
- 隔离演示实例通过真实上传/内置 worker 静态预检产生 31 个问题，验证 25+6 分页、跨页选择、搜索保留、逐条证据、嵌套返回、固定版本及授权入口；没有提交收费修复或调用模型。
- 浏览器验证实际只读成员、文件搜索/路径复制、剪贴板拒绝的手动回退、加载失败重试、轮询连接恢复与会话失效清理。
- 390×844 下库、问题抽屉和嵌套证据均无整页横向溢出；720px 宽度回流检查通过。手机操作采用浏览器模拟视口，包含保持小屏视口的 DOM 点击；不宣称真机、实际 200% 浏览器缩放或读屏认证。
