## 通用版已有，保留并补回归

以下不算新增能力：路径终点而非父目录层数判定、跨 Skill 引用锚点、文件失败处理、混合脚本扩展名覆盖、HTTP 超时/状态检查、篇幅分档与护栏不得下沉、配置凭据检查、自动化场景 --yes 例外、依赖提取、防误报和重复扣分治理。

尤其“路径检查已有”不代表全部细节相同：财务版文档补充了跨文件参数人工核提示等，A6 专门处理增量；不能把整条规则重复加入。

## 明确不迁移

- 财务 150/120 分制、科目/币种/账期检查、finws 环境安装、公司域人工介入分级。
- 内部 SSO/Cookie、SkillHub API、Multica Issue/小队/daemon、Cowork 发布与 REDoc 归档。
- 指定 fin-doc-manage 等内部工具替代用户业务实现的要求。
- 旧任务 ID、人员、业务样例、内部扫描响应原文和真实凭据。

## 评分、待复核与版本策略

保留通用 7 维度、L1 117 / L2 120、通过线 90 且零 ERR。新增版本一致性采用 0 分 ERR，不扩大满分；跨步骤检查并入已有规则，不重复扣分。新增规则 ID 与历史 ID 映射在实现时冻结。

需要人工判断的发现单独记录 reviewRequired；普通提示不自动阻断，但影响必要规则结论的未决项使本轮处于待复核，不能拿“没有 ERR”当作已完成审计。Hub 未配置属于预定义可选检查缺失，沿用规则明确的 WARN/跳过口径，不能变成必装 Hub。

本项目维护增强版 `src/skill_mng/resources/skills/skill-deep-audit/`，保留 UPSTREAM、CHANGELOG 和 MIT。平台与独立交互模式共用一份规则；独立模式不依赖本平台。版本号按实施时上游现状确定，不预占版本。内部资料只提炼通用需求并重新实现；直接复用代码须确认来源与可分发范围。未来回馈 build-better-skills 另行形成变更，本轮不修改或发布上游仓库。
