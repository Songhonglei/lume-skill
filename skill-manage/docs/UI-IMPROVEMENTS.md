# 工作台页面与交互优化 · 0.3.2.dev8

日期：2026-11-04。延续蓝色主题和「最急、最少、最像」原则，使用现有 HTML/CSS/JavaScript、FastAPI 与 SQLite，不增加前端框架、在线字体、CDN 或运行依赖。schema 仍为 4；内置独立 Skill 与审计规则未修改。

## 已完成的页面

| 页面 | 当前行为 |
| --- | --- |
| Skill 库 | 当前版本审计摘要、必修/建议数量、按结论筛选、行内审计/报告、更多菜单；名称搜索与维护者范围返回后保留 |
| Skill 详情 | 版本选择、创建审计与下载放在首屏；文件/审计修复记录/版本历史分组；摘要与登记信息按需展开 |
| 问题处理 | 必修/建议/待复核筛选、已选数量与就近修复；问题抽屉展示建议、验证和所审版本文件片段，支持文件行号定位与选择联动 |
| 报告与文件 | 复审登记后无独立任务的报告也可直接阅读；安全阅读视图、章节目录、原文切换、代码行号；大文本限制阅读渲染长度，原文与下载保持完整；手机目录按需展开 |
| 修复详情 | 修复/复审阶段、结果摘要、逐轮文件差异和语义色；保留候选、复审报告与原版本身份 |
| 导入 | 选择或拖入 ZIP 后自动检查，文件摘要与更换入口；缺项补填、服务器错误后可修正重试；目录确认保持浏览器原生 |
| 任务中心 | 执行状态与审计结论分开；完整筛选范围统计；轮询只提示更新，保留键盘焦点和正在操作的 DOM；手机使用卡片和折叠筛选 |
| 设置 | 模型、机器、成员、运行信息分组；未保存模型输入在当前登录会话内保留，保存前不允许误测旧配置；退出或登录过期返回登录页时清理临时草稿 |

蓝色用于主要动作和选中；失败、通过、待处理同时用文字与语义色区分。辅助文字对比提升，字号、圆角、间距、按钮和表单层级统一。原系统字体继续本地使用，优先保证中文、离线可用与稳定布局。

## 实现边界

- `static/ui.js`：状态标签、安全文档阅读、行号、弹窗和键盘行为。
- `static/workspace.js`：库、版本、审计、修复、任务和更新提示。
- `static/settings.js`：设置分组及成员/机器列表。
- `static/app.js`：登录、请求、路由、导入与已有写操作。
- `workspace.py` 和 history 只读摘要：查询聚合到版本，流式丢弃大报告正文；接口增量见 [REGISTRY.md](contracts/REGISTRY.md)。

阅读视图不是完整 Markdown 解释器：支持标题、列表、表格、引用、链接与代码块；不执行内嵌 HTML、脚本或图片请求。需要精确内容时切换原文。报告下载仍使用原始冻结字节；静态得分不代表完整语义 PASS。目标文件和候选写入边界、维护者权限、CSRF、机器凭据与独立复审保持原契约。
