# 导入反馈与应用弹窗 · 2026-11-03

版本 **0.3.2.dev7**，schema 仍为 4。目录选择后的浏览器“上传”按钮原本只把文件交给页面，页面还在等待第二次点击“导入”，也没有选择后的处理状态。这次改为 ZIP/目录选择完成后自动上传并检查。

- 使用工作台配色的文件选择按钮、文件数量/大小和可展开清单；处理期间显示状态和加载指示，阻止重复提交、切换方式和提前关闭。
- 根部缺少 `SKILL.md`、文件数和体积超限会在上传前提示；包内容仍由服务端完整校验。
- 缺少名称或版本时保留已上传的冻结草稿，提示补填并点击“完成导入”，不会修改包内原文。
- 服务端错误在弹窗内显示，恢复重试入口。等待超过 120 秒恢复操作，同时提示先查库确认结果；客户端超时不代表服务端撤销登记。
- 表单必填/格式错误在应用内显示并聚焦字段，不弹浏览器默认校验气泡。停用账号、停止任务、撤销机器/接入码使用统一确认窗口；取消和 Escape 不执行操作。
- 导入、审计、修复和确认窗口沿用统一样式及标题标签，窄屏可滚动，支持键盘焦点。

**浏览器边界**：操作系统文件选择器和目录文件访问确认属于浏览器安全界面，网页不能替换样式或绕过。目录选择仍保留该确认；确认完成后应用自动处理。没有用自定义弹窗冒充系统授权。

## 实际验证

独立合成实例验证了目录与 ZIP 自动登记、补版本完成、重复导入复用、无效目录/损坏 ZIP、上传中重复提交、超时恢复及确认窗口的取消和提交。三份合成包反复操作后各保留一个版本，补填版本未改变原始 `SKILL.md`。忙碌状态用暂停真实请求观测，超时用模拟传输和定时器分支验证；原生权限框由用户操作，未自动点击。

现有 **179 项 Python 测试通过**，Ruff、JS 语法和锁文件检查通过；桌面 1440×900 和手机 390×844 截图均已检查。源码/wheel/sdist 字节比对另行执行；本地检查不冒充本次新提交的 GitHub CI 结果。未配置或调用模型，原模型调用预算不变。
