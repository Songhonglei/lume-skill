## 本轮规则

- 标题能说清的，不再加一句空泛说明。版本、范围、数量等有效上下文保留。
- 按钮直接写动作；提示先说当前状态，必要时说明下一步。
- 同一结论在列表、任务与报告中使用同样的文字和颜色。
- 说明只在相关位置出现。审计方式切换时更新提示，修复文件较多时按需展开。
- 保留修复授权、版本切换、原包不变、模型调用次数和异常恢复的必要说明。
- Skill 原文、已保存的审计报告和历史验收记录不改写。
