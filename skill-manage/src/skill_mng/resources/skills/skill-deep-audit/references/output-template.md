# Frozen output contract

Canonical output is generated by scripts/audit_package.py: result.json and report.md.
Never write inside the audited Skill. Fields and CLI options are in machine-contract.md.

The Markdown includes verdict, score/maxScore, ERR/WARN counts, reviewRequired,
versionId, contentDigest, ruleVersion, and every finding with location, suggestion
and verification. Preserve report bytes on retransmission; SHA-256 is reportDigest.
JSON includes the exact Markdown, checkedRuleIds, semanticCompleted and repairPrompt.

Show ERR first, then WARN and REVIEW. Zero-point ERR must be called out even when
score equals maxScore. Required unresolved conclusions block PASS. A missing optional
Hub produces D7-W1 WARN at L2. A confirmed FAIL takes priority over review_required;
reviewRequired remains true if the audit is incomplete.

Score rules: points are deducted once per rule, not per occurrence. Full maxima are
117 (L1), 120 (L2); PASS requires >=90, zero ERR and complete rule/evidence coverage.
repairPrompt is a suggested scope only. It does not authorize a write or repair task.
Independent artifact creation does not imply platform delivery; only the platform
can declare delivery_status=saved after its transaction commits.
